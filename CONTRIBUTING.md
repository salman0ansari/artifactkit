# Contributing

ArtifactKit accepts focused parser, safety, provenance, and agent-interface improvements.

## Development

Use Go 1.25 or newer, then run:

```bash
go test ./...
go test -race ./...
go vet ./...
go build ./cmd/artifactkit
```

Binary fixtures in `testdata` are generated by Go code. After changing the generator, run:

```bash
go run ./testdata/generate.go
```

Generated fixtures must be deterministic. Run the generator twice and compare hashes when changing package output.

## Parser requirements

A parser contribution should:

- use the normalized artifact model instead of returning one unstructured text blob;
- preserve the strongest source locator the format exposes;
- honor context cancellation and all applicable limits;
- never execute macros, formulas, scripts, active content, or embedded programs;
- include valid real-file fixtures plus malformed and limit tests;
- expose large embedded content as lazy resources instead of reading it eagerly.

Keep commit messages short and imperative, matching the repository history.
